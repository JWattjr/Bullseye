# Research limits

Official [GenLayer developer documentation](https://docs.genlayer.com/developers) and the installed SDK were used for contract, equivalence-principle, finality and client integration. Actual validator probes and finalized receipts determine what this MVP claims to support; ordinary browser retrieval does not establish validator accessibility.

The saved Claude review's reward estimates were treated as hypotheses. On October 4, the authenticated [Portal submission form](https://portal.genlayer.foundation/submit-contribution) and [Projects guidance](https://portal.genlayer.foundation/contribution-type/41) were inspected directly. The form requires seven project application fields, website and repository evidence; it supports Studio explorer address links and makes video optional. Its quality bar requires a real trust problem, authoritative evidence, accurate source/docs, genuine contract interaction and lifecycle handling, and differentiation from boilerplate. [PORTAL.md](PORTAL.md) maps the prepared package to those current fields. No additive award total, eligibility guarantee or promised score follows from that inspection.
